# Task Tracker CLI

A command-line Task Tracker built with Node.js.

This project is part of the roadmap.sh Backend Projects.

## Features

- Add tasks
- Update tasks
- Delete tasks
- Mark tasks as in progress
- Mark tasks as done
- List all tasks

## Technologies

- Node.js
- JavaScript
- Git
- JSON
